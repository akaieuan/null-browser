# One hostname per line. Blank lines and `#` comments are ignored.
# `generate.mjs` turns this file into src-tauri/src/blocklist/ads.json,
# which is compiled into a WKContentRuleList at launch.
#
# This list is written here, by hand. Nothing in it is imported from
# EasyList, uBlock Origin, Peter Lowe, or any other filter project.
# Growing it is a commit, never a fetch (invariant 2).
#
# The bar for an entry: the hostname exists to serve advertising, to
# measure a person across sites, or to sell an audience segment. A
# hostname that also carries pages a user reads, or a login a user
# needs, does not go in — a dashboard behind an ad company's domain is
# still a dashboard, and breaking it is not blocking an ad. When only
# a company's collector subdomain qualifies, the entry names that
# subdomain rather than the registrable domain.
#
# Each entry matches the hostname and every subdomain of it.
